# Edit cave content

Read the relevant section below and [README.md](../../../README.md). Resolve paths
from the repository root. Keep asset `.meta` GUIDs when regenerating existing files.

## Chapters and story

Chapters 1–3 are objects in `Assets/Scenes/GameScene.unity`. Chapters 4–6 are
`Assets/Resources/Levels/level4.txt` through `level6.txt`, generated by
`Tools/generate_levels.py`. `PlayerController` loads text assets in ordinal filename
order after the scene chapters. Use sortable names when expanding the chapter set;
check `Story.Chapters` and saved chapter indices too.

Choose the source before editing: generators overwrite the three generated maps.
If the user hand-edited a map, inspect the diff before running regeneration. Prefer
updating waypoints/radii in the generator when that represents the desired change.

Map rules: `#` rock, `.` open, exactly one `S` start, `F` exit, `T` chapter gate,
`B` pickup, `< > ^ v` wind. Headers include `@ name` and `@ gravity` with a decimal
point. `LevelBuilder.Cell` is 2 world units; `S` becomes the world origin and map
rows run downward. Gates span the narrower open cross-section. Wind regions become
bounding-box triggers; irregular regions can therefore affect additional open cells.

Run `python3 Tools/generate_levels.py` after generator changes. It checks reachability
of exits/pickups/gates and clearance along the authored spine, then writes all three
maps. Inspect the resulting diff. For hand-edited maps validate the actual saved map
as well: regenerating only tests the generator's output. These checks do not simulate
the Rigidbody, wind or jittered wall geometry; play through the changed passage.

`Story.cs` holds short chapter lines, `main|sub` intro beats, ending and death text.
Keep intro skippable and chapter text over live play; avoid adding reading gates.

## Endless and daily caves

Tune width, gravity, drift and spawning in `EndlessCave.cs`; use the same seed for
before/after comparisons. Check safe entry, later narrow passages and cleanup behind
the player. Do not claim deterministic global daily geography across time zones:
daily seeds use `GameSave.DailyId`, based on the device's local date.

## Audio

`python3 Tools/generate_audio.py` writes mono 16-bit, 22050 Hz WAVs under
`Assets/Resources/Audio`. Runtime names are `tap`, `start`, `pickup`, `secret`,
`level`, `win`, `crash`, `ambient`. `GameAudio` silently skips missing files, so
check the filenames as well as listening in the game.

Regenerate audio only when needed: noise in the crash cue is not seeded before
generation, so a rerun can change that binary without a source edit. Listen for
clipping, cue balance, mute persistence and the ambient loop seam. There are seven
one-shot cues and one ambient loop. Synthesized audio is original; do not extend
that licensing claim to the third-party particle/visual assets.
